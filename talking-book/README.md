# הספר המדבר

אתר שמקריא ספרים. מוסיפים ספר (EPUB, PDF, DOCX, TXT או הדבקת טקסט), לוחצים על הפעלה ומקשיבים, בטלפון או במחשב.

- **שני מנועי קול:** קול טבעי של Google Cloud Text-to-Speech (צריך מפתח API), או קול המכשיר (חינם, בלי הגדרות).
- **עם הקול של Google:** ההקראה ממשיכה כשהמסך כבוי, אפשר לשלוט בה ממסך הנעילה ומהאוזניות, ואפשר להוריד פרקים מראש להאזנה בלי אינטרנט.
- **ניהול ההאזנה:** ספרייה של כמה ספרים, ולכל ספר נשמר המקום שבו עצרתם. יש פרקים, מהירות, טיימר שינה, ותצוגת טקסט שמסמנת את המשפט שמוקרא.
- **אין שרת:** הכל נשמר בדפדפן, ב־IndexedDB. המפתח של Google נשמר רק במכשיר.
- **אפשר להתקין:** האתר הוא PWA, ואפשר להוסיף אותו למסך הבית.

## העלאה לאינטרנט

זה אתר סטטי בלי שלב בנייה. מעלים את התיקייה `talking-book` כמו שהיא.

- **Netlify:** נכנסים ל־app.netlify.com/drop וגוררים את התיקייה.
- **Vercel / Netlify עם GitHub:** מחברים את הריפו ומגדירים Base directory: `talking-book`, בלי פקודת build.
- **GitHub Pages:** האתר יהיה זמין בכתובת `https://<user>.github.io/<repo>/talking-book/`.

האתר חייב לרוץ ב־HTTPS כדי שההתקנה למסך הבית והעבודה בלי אינטרנט יעבדו. בכל השירותים האלה זה מובנה.

## קבצים

- `index.html`, `styles.css`, `app.js`: האתר עצמו.
- `sw.js`: עבודה בלי אינטרנט.
- `manifest.webmanifest`, `icons/`: התקנה למסך הבית.
- `vendor/`: PDF.js, JSZip ו־Mammoth, לקריאת קבצים. נטענים רק כשפותחים קובץ. הרישיונות נמצאים ב־`vendor/licenses`.
