הקול שמקריא

חיבור לקולות של Google

איך משיגים מפתח (בערך 5 דקות, פעם אחת)
  1. נכנסים ל־console.cloud.google.com ומתחברים עם חשבון Google.
  2. יוצרים פרויקט חדש, למשל בשם talking-book.
  3. מפעילים חיוב (Billing). צריך כרטיס אשראי. יש מכסה חינמית חודשית, ולחשבון חדש יש בדרך כלל גם קרדיט התחלתי.
  4. בתיבת החיפוש למעלה כותבים Cloud Text-to-Speech API, נכנסים ולוחצים Enable.
  5. בתפריט: APIs & Services ← Credentials ← Create credentials ← API key. מעתיקים את המפתח.
  6. מומלץ: לוחצים על המפתח ומגבילים אותו ל־Cloud Text-to-Speech API בלבד, ולכתובת של האתר הזה (Website restrictions).
  7. מדביקים כאן ולוחצים "שמירה ובדיקה".

כדאי להגדיר ב־Google התראת תקציב (Budget alert) כדי לא להיות מופתעים. המחירון העדכני: cloud.google.com/text-to-speech/pricing.

להעביר את החיבור לטלפון מעתיקים קישור, שולחים אותו לעצמכם (למשל בוואטסאפ) ופותחים בטלפון. אל תשתפו אותו עם אחרים, כי המפתח בתוכו.
