קריינים טבעיים

קולות של Google שנשמעים כמו קריין אמיתי. ממשיכים לנגן כשהמסך כבוי, ואפשר להוריד פרקים מראש לנסיעה. מחברים פעם אחת עם מפתח.

איך משיגים מפתח? בערך 5 דקות, פעם אחת
  1. נכנסים ל־console.cloud.google.com ומתחברים עם חשבון Google.
  2. יוצרים פרויקט חדש, למשל בשם hed.
  3. מפעילים חיוב (Billing). צריך כרטיס אשראי. יש מכסה חינמית חודשית, ולחשבון חדש יש בדרך כלל גם קרדיט התחלתי.
  4. בתיבת החיפוש למעלה כותבים Cloud Text-to-Speech API, נכנסים ולוחצים Enable.
  5. בתפריט: APIs & Services ← Credentials ← Create credentials ← API key. מעתיקים את המפתח.
  6. מומלץ: לוחצים על המפתח ומגבילים אותו ל־Cloud Text-to-Speech API בלבד, ולכתובת של האתר (Website restrictions).
  7. מדביקים כאן ולוחצים "חיבור".

כדאי להגדיר ב־Google התראת תקציב (Budget alert). המחירון העדכני: cloud.google.com/text-to-speech/pricing.
