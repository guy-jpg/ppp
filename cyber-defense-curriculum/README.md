# 🛡️ מסלול הכשרה לסייבר הגנתי — רמה מתקדמת

> נבנה עבור הנדסאי שמתגייס לחיל התקשוב וההגנה בסייבר. מטרה: להגיע ליום הגיוס עם בסיס חזק ומעשי בכל התחומים הליבתיים של הגנת סייבר (Blue Team), ניתוח, וחקירה.

**אופי החומר:** הגנתי, חינוכי, מעשי. כל מעבדה מתבצעת בסביבה מבוקרת ומבודדת שלך (VM / lab) בלבד.

## 🗓️ תוכנית 4 חודשים (16 שבועות)

### חודש 1 — תשתית (Foundations)
- **שבוע 1-2:** יסודות רשתות (`00`) — TCP/IP, פרוטוקולים, מודל OSI, captures ב-Wireshark
- **שבוע 3-4:** Linux (`01`) — CLI, הרשאות, שירותים, bash, hardening

### חודש 2 — כלים והתקפה (כדי להבין הגנה)
- **שבוע 5-6:** Python (`02`) — אוטומציה, סוקטים, פרסור לוגים, כלי קטן משלך
- **שבוע 7:** Metasploit (`04`) — בסביבת lab סגורה, להבין שרשרת תקיפה
- **שבוע 8:** MITRE ATT&CK (`07`) — מיפוי כל מה שלמדת לטכניקות

### חודש 3 — הגנה אקטיבית (Blue Team)
- **שבוע 9-10:** IDS/IPS (`08`) — Suricata/Snort, כתיבת חתימות, ניתוח התראות
- **שבוע 11:** pfSense (`06`) — firewall, סגמנטציה, VPN
- **שבוע 12:** Windows Forensics (`05`) — חקירת אירוע מקצה לקצה

### חודש 4 — ענן, AI, ואינטגרציה
- **שבוע 13-14:** AWS (`03`) — IAM, security groups, CloudTrail, GuardDuty
- **שבוע 15:** AI in Cyber (`10`) — אנומליות, LLM ב-SOC, איומי AI
- **שבוע 16:** Cyberium Arena (`09`) + פרויקט מסכם — תרגול אינטגרטיבי

## 🧪 הקמת מעבדה (חובה לפני שמתחילים)

מומלץ מאוד לעבוד בסביבה מבודדת. ראה `labs/LAB-SETUP.md` למדריך מלא. בקצרה:
- **Hypervisor:** VirtualBox / VMware / Proxmox
- **VMs מומלצים:**
  - Kali Linux (כלי תקיפה ובדיקה)
  - Ubuntu Server (יעד / שרת לוגים)
  - Windows 10/11 (forensics + יעד)
  - pfSense (router/firewall בין הרשתות)
  - Security Onion / Suricata (ניטור IDS)
- **רשת:** Host-Only / Internal Network — **בלי גישה לאינטרנט בזמן תרגילי תקיפה**.

## 🎓 איך ללמוד נכון (מתודולוגיה)
1. **קרא** את ה-`COURSE.md` של הנושא — תיאוריה + הסבר.
2. **תרגל** את ה-`labs` / התרגילים בסוף כל קורס.
3. **תעד** — פתח מחברת (Markdown / Obsidian) וכתוב מה למדת.
4. **חבר לעולם האמיתי** — לכל טכניקה, שאל "איך מזהים את זה? איך עוצרים?".
5. **חזור** — חזרה מרווחת (spaced repetition) על מושגי מפתח.
