# 🤖 סוכן וואטסאפ לתזכורות

סוכן אישי לוואטסאפ שמבין הודעות בעברית בשפה חופשית ומחזיר לך תזכורות בזמן שביקשת.

> דוגמה: שולחים לסוכן "תזכיר לי מחר בבוקר ב-9 לקנות חלב" — והוא ישלח לך הודעה מחר ב-9:00.

## איך זה עובד

```
הודעת וואטסאפ ──▶ whatsapp-web.js ──▶ Claude API (פירוש לשפה מובנית)
                                              │
                                              ▼
                                    אחסון תזכורות (JSON)
                                              │
                                       מנוע תזמון (כל 30 ש')
                                              │
                              ◀── שליחת תזכורת בזמן הנכון ──
```

- **whatsapp-web.js** — מתחבר למספר הוואטסאפ האישי שלך דרך סריקת QR (חינמי, לא רשמי).
- **Claude API** — מפרש שפה חופשית בעברית, כולל זמנים יחסיים ותזכורות חוזרות.
- **אחסון בקובץ** — התזכורות נשמרות ב-`data/reminders.json` ושורדות אתחול של השרת.

## דרישות מוקדמות

- Node.js 18 ומעלה
- מפתח API של Claude מ-[console.anthropic.com](https://console.anthropic.com)
- מספר וואטסאפ פעיל בטלפון

## התקנה והרצה מקומית

```bash
cd whatsapp-reminder-agent
npm install
cp .env.example .env
# ערוך את .env והכנס את ANTHROPIC_API_KEY
npm start
```

> אם ההתקנה נכשלת בגלל גרסה לא זמינה, הרץ:
> `npm install @anthropic-ai/sdk@latest whatsapp-web.js@latest dotenv qrcode-terminal`

בהרצה הראשונה יוצג קוד QR בטרמינל. בטלפון: **וואטסאפ → הגדרות → מכשירים מקושרים → קישור מכשיר** וסרוק.
לאחר הסריקה הסשן נשמר ב-`.wwebjs_auth/` ולא צריך לסרוק שוב.

## שימוש

שלח הודעה לסוכן (ראה "איך לשלוח לסוכן" למטה). דוגמאות:

| מה שולחים | מה קורה |
|-----------|---------|
| `תזכיר לי בעוד שעתיים להתקשר לאמא` | תזכורת חד-פעמית בעוד שעתיים |
| `כל יום בשעה 8 תזכיר לי לקחת תרופה` | תזכורת חוזרת יומית |
| `מה התזכורות שלי?` | רשימת התזכורות הפעילות |
| `בטל את כל התזכורות` | מחיקת כל התזכורות |

### איך לשלוח לסוכן

הסוכן רץ על מספר הוואטסאפ שחיברת. שתי אפשרויות נפוצות:
1. **מספר ייעודי** — חבר מספר נפרד לסוכן, ושלח לו הודעות מהטלפון הראשי שלך.
2. **המספר האישי** — תוכל להשתמש בצ'אט "הודעה לעצמי" כדי לשלוח פקודות לסוכן.

מומלץ להגדיר `ALLOWED_NUMBERS` ב-`.env` כדי שרק אתה תוכל לתפעל את הסוכן.

## הרצה על שרת ענן (VPS) 24/7

1. העלה את הקוד לשרת (Railway / Render / DigitalOcean / VPS רגיל).
2. ודא ש-Chromium וספריות המערכת הדרושות ל-Puppeteer מותקנות (ב-Debian/Ubuntu):
   ```bash
   sudo apt-get update && sudo apt-get install -y \
     chromium ca-certificates fonts-liberation libnss3 libatk-bridge2.0-0 \
     libgtk-3-0 libasound2 libgbm1
   ```
3. הגדר משתני סביבה (`ANTHROPIC_API_KEY` וכו').
4. הרץ עם מנהל תהליכים כדי שיעלה אוטומטית אחרי אתחול/קריסה:
   ```bash
   npm install -g pm2
   pm2 start src/index.js --name whatsapp-agent
   pm2 save && pm2 startup
   ```
5. הסריקה הראשונה של ה-QR דורשת גישה לטרמינל (`pm2 logs whatsapp-agent`). לאחר מכן הסשן נשמר.

> טיפ: גבה את תיקיית `.wwebjs_auth/` כדי לא לסרוק QR מחדש בכל פריסה.

## מבנה הפרויקט

```
whatsapp-reminder-agent/
├── src/
│   ├── index.js      — נקודת כניסה, חיבור וואטסאפ וניתוב הודעות
│   ├── claude.js     — פירוש שפה חופשית ל-JSON מובנה (Claude API)
│   ├── scheduler.js  — מנוע התזמון ששולח תזכורות בזמן
│   └── storage.js    — שמירת תזכורות בקובץ JSON
├── .env.example
└── package.json
```

## הערות ומגבלות

- whatsapp-web.js הוא ספרייה **לא רשמית** המבוססת על וואטסאפ ווב. בשימוש אישי סביר זה יציב, אך תאורטית קיים סיכון לחסימה. אל תשתמש בזה לספאם.
- אם תתנתק מ"מכשירים מקושרים" בטלפון, תצטרך לסרוק QR מחדש.
- המנוע בודק תזכורות כל 30 שניות, כך שהדיוק הוא ברמת חצי דקה.
