# GTA VII — Liberty Shores 3D 🚗🌆

משחק נהיגה **תלת-ממדי** בעיר פתוחה, בהשראת סדרת GTA, שנבנה על **Three.js / WebGL**
עם דגש על **גרפיקה ותאורה**: חומרי PBR, צללים רכים (PCF), מחזור יום/לילה דינמי,
עיר עם חלונות מוארים, ערפל, tone-mapping קולנועי ומצלמת מרדף.

## ▶️ הפעלה
פתח את `index.html` בדפדפן מודרני (Chrome / Edge / Firefox / Safari).
המשחק טוען את מנוע Three.js מ-CDN, לכן נדרש חיבור אינטרנט בהרצה הראשונה.

## שליטה
- **חיצים / WASD** — גז, בלם והיגוי
- **רווח** — בלם יד (סחרור)
- **N** — מעבר יום / לילה ☀️🌙
- **C** — החלפת זווית מצלמה (מרדף / גבוה / מכסה מנוע)
- במובייל — דוושות והגה מגע מופיעים אוטומטית

## מה יש במשחק
- 🏙️ **עיר 3D פרוצדורלית** — רשת רחובות עם סימוני נתיב ומעברי חצייה, מגדלים בגבהים
  משתנים, חלונות שמתאירים בלילה, גגות מפורטים, פארקים ועצים
- 💡 **תאורה דינמית** — שמש מכוונת עם צללים רכים שעוקבים אחרי הרכב, אור המיספרה,
  ערפל אטמוספרי, ובלילה — פנסי הרכב מאירים את הכביש וכל העיר נדלקת
- 🚙 **רכב מפורט** — גוף מתכתי מבריק, זכוכית שקופה, גלגלים מסתובבים, פנסים קדמיים/אחוריים
- 🚦 **תנועה חיה** — מכוניות נוסעות ברחבי העיר
- 🚓 **משטרה + מערכת כוכבי מבוקש (1–5)** — ניידות עם פנסים מהבהבים שרודפות אותך
- 🎯 **משימות מתחלפות** עם פרסי כסף, ועמוד אור זוהר שמסמן את היעד
- 🎥 שלוש זוויות מצלמה, מד מהירות, מד נזק לרכב ו-HUD מלא
