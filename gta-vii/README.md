# SPEED RIVALS — Kart Racing 🏎️🏁

משחק **מירוצי קארטינג** תלת-ממדי בסגנון ארקייד (בהשראת ז'אנר ה-kart racers כמו
Speedstorm / Mario Kart), עם נכסים מקוריים, שנבנה על **Three.js / WebGL**.

> הערה: זהו משחק מקורי בהשראת הז'אנר — הוא **אינו** משכפל את Disney Speedstorm,
> הדמויות או המותגים שלו (תוכן מוגן בזכויות יוצרים).

## ▶️ הפעלה
פתח את `index.html` דרך מארח שמגיש קבצים אמיתיים (GitHub Pages, raw.githack.com,
שרת מקומי). המשחק טוען את מנוע Three.js מ-CDN, לכן נדרש חיבור אינטרנט.
> ⚠️ htmlpreview.github.io **לא** מתאים — הוא מזריק סקריפטים ושובר את סדר הטעינה.

## שליטה
- **חיצים / WASD** — גז, בלם והיגוי
- **רווח** — **דריפט**: החזק בפנייה כדי לצבור בוסט, שחרר לזינוק מהירות 💨
- **N** — מעבר יום / לילה ☀️🌙
- **C** — החלפת זווית מצלמה (מרדף / גבוה / קוקפיט)

## מה יש במשחק
- 🏎️ **קארט מירוץ מפורט** — שלדה, חרטום, ספוילר אחורי, נהג עם קסדה וויזור,
  הגה, גלגלים אחוריים גדולים שמסתובבים וגלגלים קדמיים שמסובבים בהיגוי
- 🛣️ **מסלול מירוץ סגור** (Catmull-Rom) עם אספלט מסומן, **מעקות קארב אדום-לבן**,
  קו זינוק/סיום משובץ, יציעים ועצים מסביב
- 💨 **דריפט-בוסט** עם 3 דרגות טעינה (כחול → כתום → סגול), ניצוצות בגלגלים האחוריים
  ו-FOV שנפתח לתחושת מהירות
- ⚡ **משטחי בוסט** על המסלול
- 🤖 **3 יריבים ממוחשבים** שעוקבים אחרי קו המירוץ
- 🏁 **3 הקפות**, מד מיקום חי (מקום 1/4), ספירה לאחור 3·2·1·GO ומסך תוצאות עם מדליה
- 💡 תאורה דינמית, צללים רכים, ערפל ו-tone-mapping קולנועי; מצב יום/לילה עם פנסים
