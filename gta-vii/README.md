# GTA VII — Liberty Shores 🚗💨

משחק אקשן דו-ממדי במבט-על (top-down), בהשראת סדרת GTA, שנבנה כולו ב-HTML5 Canvas
ללא ספריות חיצוניות. פתח את `index.html` בדפדפן והתחל לשחק.

## איך משחקים
- **חיצים / WASD** — תנועה ברגל ונהיגה ברכב
- **F** — כניסה / יציאה מרכב (התקרב לרכב כדי לגנוב אותו)
- **רווח** — ירי (כשאתה ברגל)
- במובייל — שלט מגע מופיע אוטומטית

## מה יש במשחק
- 🏙️ עיר פתוחה עם רשת כבישים, בניינים ומפה קטנה (minimap)
- 🚙 תנועה אוטומטית של מכוניות שאפשר לגנוב
- 🚶 הולכי רגל שנבהלים ובורחים
- 🚓 משטרה עם **מערכת כוכבי מבוקש** (1–5) — ככל שתפשע יותר, יותר שוטרים ירדפו אותך
- 🎯 משימות מתחלפות: נהיגה ליעד, משלוחים, ומשימות מתוזמנות
- 💰 כסף, 🩹 חבילות חיים ופאוור-אפים ברחבי העיר
- 💥 חלקיקים, צמיגים חורקים ואפקטים

## מבנה
```
gta-vii/
├── index.html      # מבנה + HUD + מסכים
├── styles/main.css # עיצוב
└── game.js         # מנוע המשחק כולו
```

נבנה לשם הכיף. כל הדמיון ל-Liberty City מקרי בהחלט. 😎
