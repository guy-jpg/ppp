‫Flame (2012): כשהתנגשות הופכת לנשק‬

‫נוזקת ריגול מתוחכמת שהתגלתה ב־2012 במחשבים במזרח התיכון.‬

‫התוקפים יצרו התנגשות MD5 מסוג Chosen-Prefix מול תעודה של שירות Microsoft Terminal Server Licensing.‬

‫התוצאה: תעודה מזויפת שחתימת Microsoft תקפה עליה — והנוזקה הופצה כאילו הייתה עדכון Windows Update רשמי.‬

‫הלקח: התנגשות אחת = חתימה דיגיטלית שאפשר להעביר למסמך אחר.‬
