‫איך מתגוננים: HMAC ושאר הפתרונות‬

HMAC(K, m) = H( (K ⊕ opad) ‖ H( (K ⊕ ipad) ‖ m ) )

‫הגיבוב החיצוני ’סוגר’ את הפנימי — התוקף לא מקבל מצב שאפשר להמשיך ממנו.‬

‫חלופות: SHA-3 / KMAC, מפתח מובנה ב־BLAKE2 / BLAKE3, או גרסאות קטומות כמו SHA-512/256 ו־SHA-384.‬

‫בשטח: HMAC-SHA256 נמצא ב־TLS, ב־IPsec, ב־JWT (HS256) ובחתימות API של AWS (SigV4).‬
