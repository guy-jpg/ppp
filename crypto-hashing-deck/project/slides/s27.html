‫חלק 3 · Length Extension‬

‫תקיפת Length Extension — צעד אחר צעד‬

1

‫השרת מאמת בקשות כך:‬

tag = SHA-256(secret ‖ message)

‫הסוד ידוע רק לשרת.‬

2

‫התוקף רואה בקשה חוקית:‬

user=dana&role=user

‫ואת התג שלה.‬

3

‫התוקף מנחש את אורך הסוד, מחשב את הריפוד, וממשיך את השרשרת מהתג עם ‎&role=admin.‬

4

‫התוצאה: תג חוקי ל־secret ‖ message ‖ padding ‖ &role=admin — בלי שהתוקף ראה את הסוד אף פעם.‬

‫הבקשה המזויפת:‬

user=dana&role=user

&role=admin

‫את אורך הסוד התוקף פשוט מנחש — מנסה 8, 16, 32 בתים, ושולח כמה ניסיונות. שרתים רבים מתעלמים מהבתים המוזרים באמצע ולוקחים את הערך האחרון של role.‬
